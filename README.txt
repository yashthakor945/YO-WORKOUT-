YO WORKOUT — Netlify upload instructions

1. Extract this ZIP file.
2. In Netlify Drop, upload the CONTENTS of this folder together (not the ZIP itself and not index.html alone).
3. Keep index.html, manifest.webmanifest, sw.js, icon-192.png and icon-512.png at the top/root level.
4. Open the deployed HTTPS website in Google Chrome on your phone.
5. Tap Chrome menu (three dots) > Install app. If Install app is not shown, use Add to Home screen.
6. Open YO WORKOUT from the Home Screen.

The tracker saves tick records in this browser's local storage. Clearing browser/site data can erase them.
